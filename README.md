# 🏥 Healthcare Revenue Intelligence System

## 🌟 What is this Project?

This project is a smart healthcare analytics system that helps hospitals understand:

- Where they are losing money
- Why insurance claims are getting rejected
- Which departments have payment delays
- How risky a new claim might be

It uses data analysis and machine learning to turn raw billing data into useful business insights.

---

## ❓ Why I Built This

Hospitals handle thousands of billing records.

Sometimes:
- Insurance pays less than expected
- Payments get delayed
- Claims get denied
- Revenue gets lost without clear visibility

This system helps identify these problems early using data.

---

## 🧠 What This System Can Do

✔ Generate healthcare billing data  
✔ Calculate revenue loss automatically  
✔ Detect claim denial patterns  
✔ Show department-wise financial insights  
✔ Predict whether a new claim is risky  
✔ Display everything in a simple dashboard  

---

## 📊 What Data Does It Use?

The system works with:

- Patient ID
- Hospital Department
- Insurance Type
- Claim Amount
- Paid Amount
- Payment Delay (in days)

From this, it calculates:
- Revenue Leakage
- Claim Denial Risk
- Delay Category

---

## 🤖 Machine Learning Inside

The project uses a Random Forest model to:

- Predict if a claim will be denied
- Show the probability of risk
- Help decision-makers take action early

---

## 📈 Dashboard Features

The dashboard shows:

- Total revenue loss
- Average payment delay
- Claim denial rate
- Department-level revenue breakdown
- Live risk prediction tool

Built using Streamlit so it runs as a web app.

---

## 🛠 Technologies Used

- Python
- Pandas (for data analysis)
- Scikit-learn (for machine learning)
- Streamlit (for dashboard)
- Plotly (for charts)

---

## 🚀 How to Run This Project

Step 1: Install requirements

pip install -r requirements.txt

Step 2: Generate data

python generate_data.py


Step 3: Train the model

python train_model.py


Step 4: Start dashboard

streamlit run app.py
